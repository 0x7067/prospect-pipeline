# Source manifest

Static redesign concept for Penha Moraes Arquitetura (local only, non-affiliated, noindex). Every file in the public package is listed below with its origin.

## Business-specific evidence sources (as supplied, not re-verified by this build)

- `prospect.json` — qualified prospect record (run date 2026-07-16): business name, category, address, verified public contacts, observed problems, evidence links.
- `PRODUCT.md` — evidence boundary statement for this build.
- Evidence URLs cited in the prospect record (read-only, captured 2026-07-16 by the prospecting pipeline):
  - https://penhamoraes.arq.br/
  - https://penhamoraes.arq.br/contato/
  - https://pt.linkedin.com/posts/penha-moraes-arquitetura_arquiteto-arquitet%C3%B4nico-activity-7368372319934734338-jlbI
  - https://linkedin.com/in/leticia-neves-

No business fact appears in the site unless it is present in `prospect.json` or `PRODUCT.md`. The disputed room number (401 vs 403) and the placeholder-pattern WhatsApp number are deliberately omitted.

## Authored files (written for this concept, original copy)

- `index.html` — proposed visitor experience. Original copy written for this concept; no text copied from the business site.
- `proposal.html` — outreach-facing proposal document (diagnosis, rationale, sources, limits).
- `rationale.html` — design rationale, evidence mapping, and limitations.
- `styles.css` — original design system ("Planta e Concreto": concrete neutrals + terracotta accent, OKLCH-era palette expressed in hex, stepped type/spacing scale).
- `script.js` — original progressive-enhancement interactions (mobile nav, portfolio filter, inert form validation, reveal-on-scroll). No network calls, no storage, no tracking.
- `README.md`, `SITE_REVIEW.md`, `SOURCE_MANIFEST.md` — documentation for this package.

## Bundled assets (local, no runtime external requests)

- `assets/fonts/archivo-var.woff2`, `assets/fonts/archivo-italic-var.woff2` — Archivo variable font (OFL-licensed, self-hosted subset).
- `assets/fonts/frank-ruhl-libre-var.woff2` — Frank Ruhl Libre variable font (OFL-licensed, self-hosted subset).
- `assets/img/*.jpg` — editorial architectural reference photography sourced for this concept and explicitly disclosed in-page as illustrative, never presented as work by the firm.
- `assets/img/cobogo-motif.svg` — original decorative motif drawn for this concept.

## Captures and receipts (pipeline artifacts, not part of the public package)

- `comparison/` — desktop/mobile screenshots of the current public site and of this proposed build, generated by `/opt/data/scripts/capture_curitiba_comparison.mjs`.
- `.impeccable-craft-receipt.json` — craft receipt for this AFK run.
- `.impeccable-detector-receipt.json` — pinned local detector gate receipt (must be current and status=clean before deploy-ready receipt).
- `.afk-ready-to-deploy.json` — final build receipt written only after a clean, current detector gate.

## Third-party runtime dependencies

None. No CDN, no analytics, no tag managers, no remote fonts, no form endpoints.
