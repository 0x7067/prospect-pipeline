# Curitiba Palace Hotel — Kimi variant

Static-site concept built inside the isolated `kimi-variant` directory.

## Pages

- **index.html** — production-realistic homepage concept.
- **proposal.html** — independent proposal disclosure and evidence summary.
- **rationale.html** — redirects to `proposal.html`.
- **styles.css** — responsive design system and component styles.
- **script.js** — small mobile navigation, header scroll state and smooth scroll.

## How to preview

Open `index.html` in any modern browser, or serve the directory with a static server:

```bash
cd /opt/data/projects/curitiba-rebuilds/2026-07-17/curitiba-palace-hotel/kimi-variant
python3 -m http.server 8080
```

Then visit http://localhost:8080.
