# Sarnelli Arquitetura — Redesign conceitual

## Sobre

Redesign conceitual estático para o site da Sarnelli Arquitetura, empresa especializada em arquitetura para saúde e educação, sediada em Curitiba/PR.

Este é um conceito independente baseado exclusivamente em evidências públicas verificadas em 2026-07-17.

## Estrutura

- `index.html` — Página principal de produção (sem linguagem de proposta/redesign)
- `proposal.html` — Documento de proposta independente com análise e justificativa
- `rationale.html` — Redirecionamento compatível para proposal.html
- `styles.css` — Sistema de design completo
- `script.js` — Interatividade (menu mobile, filtros, scroll)
- `SITE_REVIEW.md` — Revisão técnica e visual
- `SOURCE_MANIFEST.md` — Registro de fontes e evidências

## Design

- **Cores:** #2B2B2B (texto), #FFFFFF (fundo), #0F6358 (teal/accento), #F5F7F7 (neutro)
- **Tipografia:** Montserrat (títulos), Roboto (corpo)
- **Composição:** Sequência "pilar → prova → processo → contato"
- **Portfólio:** Filtrável por tipologia (hospitais, clínicas, escolas)

## Como visualizar

Abra `index.html` em um navegador para ver a página principal.
Abra `proposal.html` para ver a proposta de redesign.
