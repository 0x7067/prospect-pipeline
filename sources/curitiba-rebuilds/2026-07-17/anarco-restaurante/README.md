# Anarco Restaurante — Redesign estático

Redesign completo do site do Anarco Restaurante, o mais tradicional restaurante de comida italiana de Curitiba. Site estático (HTML/CSS/JS), sem dependências de backend ou framework.

## Estrutura

- `index.html` — Página principal (homepage de produção)
- `proposal.html` — Proposta de redesign (documento de venda independente)
- `rationale.html` — Redireciona para proposal.html
- `styles.css` — Folha de estilo completa
- `script.js` — Comportamentos (navegação mobile, reveal on scroll)
- `assets/` — Imagens (logo, pratos)

## Design

**Tese composicional:** "Uma mesa editorial de cozinha italiana" — a página lê como uma narrativa de mesa compartilhada, não como uma vitrine genérica de restaurante.

**Cores:** Bordô #5C0709 (hero, footer, destaques), creme #FFF8E0 (seção história), verde oliva #566B3D (acentos), rosa #CC3366 (estados de ação).

**Tipografia:** Playfair Display (títulos editoriais, nomes de pratos) + Open Sans (corpo, navegação, CTAs).

**Momentos artísticos:**
1. Hero tipográfico em bordô — sem imagem, sem overlay, apenas a marca se comunicando com sua própria linguagem publicada.
2. Faixa editorial de pratos — fotografia real em cortes amplos, sem overlays que escondam textura.
3. Bifurcação contextual por unidade — duas colunas claras com CTAs de WhatsApp específicos para Mercado Municipal e Batel.

## Deploy

Qualquer hospedagem estática: Netlify, Vercel, GitHub Pages, Cloudflare Pages. Basta subir os arquivos.
