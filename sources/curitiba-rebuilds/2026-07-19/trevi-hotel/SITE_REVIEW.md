# Site Review — Trevi Hotel &amp; Business Redesign

**Deliverable tier:** early_visual_direction
**Review date:** 2026-07-25
**Status:** Pre-validation draft

## Compositional Thesis

This concept can only belong to Trevi Hotel &amp; Business because it mirrors the dual positioning that defines the brand: a hotel that is simultaneously a practical lodging option and a business-event venue. The page layout reflects this by giving equal visual weight to stay and events — not as afterthoughts or secondary paths, but as co-equal entry points. The horizontal amenity strip (rather than card grids) communicates the practical, no-frills character of a central Curitiba hotel that prioritizes function over spectacle.

## Anti-Template Tests

### 1. Logo-removal test
**Result: Pass.** Without the logo, the burgundy header, the gold accent on labels, the dual-column stay/events split, and the practical amenity strip still communicate a business-ready central hotel. The typographic pairing (Playfair Display + Inter) reads as hospitality but with a practical edge — not a luxury resort or budget chain.

### 2. Competitor-swap test
**Result: Pass with conditions.** A generic "hotel in Curitiba" name could be swapped in, but the dual-positioning split (stay AND events with equal weight) is specific to Trevi's "Hotel &amp; Business" identity. A pure lodging competitor would not naturally have this structure. The amenity strip's emphasis on business center and event rooms further anchors this to Trevi's specific service mix.

### 3. Squint test
**Result: Pass.** At thumbnail size, the hierarchy is clear: burgundy header band, hero with text + white reservation card, two-column split with contrasting backgrounds, dark charcoal amenity strip with gold accents, then the lighter location section. The visual rhythm varies between dense (header, amenities) and open (hero, split panels).

### 4. Five-second test
**Result: Pass.** Within five seconds: (1) Brand identity — Trevi Hotel &amp; Business in the header; (2) Proposition — "Hospedagem prática no coração da capital paranaense"; (3) Memorability — the reservation bar is immediately actionable, the stay/events split is distinct from typical hotel layouts.

### 5. Below-fold test
**Result: Pass.** After the hero, the stay/events split provides a distinct compositional moment (not generic cards). The amenity strip is a horizontal band with dividers — a different visual treatment. The location section uses a two-column layout with an address card and map placeholder. Each section earns its space.

### 6. Mobile-native test
**Result: Pass.** Mobile stacks the reservation bar below the headline (reservation-first on small screens). The split panels become full-width with visual on top, content below. The amenity strip becomes a 2-column grid. Navigation collapses to a slide-out drawer with hamburger toggle. Tap targets are sized appropriately.

## Art-Direction Checklist

### Hero
- [x] Headline is emotionally persuasive and source-bounded ("Hospedagem prática no coração da capital paranaense")
- [x] CTA is unmistakable (white reservation card with burgundy "Reserve já" button)
- [x] Logo has sufficient presence and contrast in header

### Typography
- [x] Type choice relates to hospitality brand (serif display + clean sans body)
- [x] Display and body voices are intentionally paired
- [x] Line breaks are considered at desktop and mobile

### Color
- [x] Exact retained colors documented (burgundy #7B1E2E, charcoal #2C2C2C from live site)
- [x] New colors have stated purpose (gold #C4A35A for selective emphasis, off-white #F7F4F0 for warmth)
- [x] Accent color used selectively (only on labels, borders, and CTA hover states)

### Imagery
- [x] No fabricated imagery — CSS gradients as intentional placeholders for early visual direction
- [ ] Real photos needed for production (dependency noted)

### Page Rhythm
- [x] Three distinct compositional moments (type-led hero, stay/events split, amenity strip)
- [x] No repetitive cards or ruled rows
- [x] Section transitions vary density (dense header → open hero → structured split → dense strip → open location)

### Mobile
- [x] Navigation has visible open/closed state (hamburger animation)
- [x] Tap targets are at least 44x44 CSS pixels
- [x] Mobile has intentional rhythm (stacked reservation-first, full-width panels, 2-column grid)

## Known Limitations (Early Visual Direction)

1. **Images:** CSS gradient backgrounds serve as visual placeholders. Production requires real hotel photography.
2. **Booking integration:** Reservation form points to the official site but does not integrate with the actual booking engine.
3. **Map:** Placeholder visual instead of Google Maps embed.
4. **Content:** Texts are in Portuguese based on official site language but have not been reviewed by the hotel's team.
5. **Testimonials:** The live site has a depoimentos section but no extractable review content — omitted rather than fabricated.

## Conclusion

This build meets the raised style bar for an early visual direction. It is prospect-specific, has three distinct art-directed moments, passes the anti-template tests, and scores above the visual release threshold. It is explicitly not production-complete and requires the noted dependencies before publication.
