# Geração de Saúde — static site

Production-complete static homepage and a separate independent proposal document.

## Preview

Serve this directory with any static server, for example:

```sh
python -m http.server 8080
```

Open `http://localhost:8080/index.html`. No build step or package installation is required.

## Files

- `index.html`: public-facing homepage
- `proposal.html`: independent sales document
- `rationale.html`: compatibility redirect to the proposal
- `styles.css`, `script.js`: shared presentation and behavior
- `SOURCE_MANIFEST.md`, `SITE_REVIEW.md`: evidence and quality review

External links are limited to the supplied first-party contact destination and verified phone number. The page contains no form submission or external service integration.
