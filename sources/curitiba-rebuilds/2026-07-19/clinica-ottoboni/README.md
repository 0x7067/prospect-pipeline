# Clínica Ottoboni — direção visual inicial

Site estático responsivo construído como um “atlas de consulta”: necessidade/especialidade → integração → contato.

## Arquivos

- `index.html`: homepage pública realista
- `proposal.html`: documento comercial independente
- `rationale.html`: redirecionamento compatível para a proposta
- `styles.css`, `script.js`: apresentação e interação
- `SOURCE_MANIFEST.md`, `SITE_REVIEW.md`: limites de evidência e revisão

Abra `index.html` em um navegador ou sirva a pasta com um servidor HTTP local. Não há dependências, formulários, analytics, fontes remotas ou chamadas de rede. Esta entrega é `early_visual_direction`: demonstra tese, hierarquia, responsividade e interação, mas não está aprovada, pronta para publicação ou completa para produção.

## Verificação local

O conjunto foi verificado com o validador do projeto. A revisão registrada em `SITE_REVIEW.md` é uma autoavaliação de construção, não aprovação humana, clínica ou comercial.
