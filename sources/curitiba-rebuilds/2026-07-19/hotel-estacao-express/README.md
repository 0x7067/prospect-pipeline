# Hotel Estação Express — early visual direction

Static, evidence-bounded website concept. Open `index.html` directly or serve the directory with any static file server.

## Files

- `index.html`: public-facing homepage concept
- `proposal.html`: independent persuasive proposal
- `rationale.html`: compatibility redirect to the proposal
- `styles.css`, `script.js`: shared presentation and menu behavior
- `SOURCE_MANIFEST.md`: evidence ledger
- `SITE_REVIEW.md`: design and validation review

## Status

This deliverable is an **early visual direction**, not a production-complete site and not ready for publication. It intentionally omits unverified rates, availability, room categories, contacts, policies, and booking integration. External links route only to the supplied official hotel URL and OpenStreetMap location.
