# Poncio Contabilidade

Site estático híbrido para Poncio Contabilidade, com direção editorial própria e caminho de conversão por situação empresarial.

## Arquivos
- `index.html` — página pública.
- `styles.css` — tokens, layout responsivo e acessibilidade.
- `script.js` — menu móvel.
- `proposal.html` — página auxiliar de direção.
- `rationale.html` — redirecionamento somente para `proposal.html`.
- `SITE_REVIEW.md` — revisão factual dos checks executados.
- `SOURCE_MANIFEST.md` — origem dos fatos e limites de conteúdo.

## Execução local
Sirva este diretório com qualquer servidor HTTP local ou abra `index.html` diretamente. O site não usa CDN, fontes externas, chamadas de serviço, formulários ou envio de dados.
