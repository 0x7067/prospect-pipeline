# Clínica Curitiba de Odontologia

Site estático híbrido: identidade dental distintiva, posicionamento claro, prova contextual e caminho simples para ligar e agendar.

## Arquivos

- `index.html` — homepage pública; não faz referência à proposta.
- `proposal.html` — conceito independente e racional de negócio.
- `rationale.html` — redirect-only para `proposal.html`.
- `styles.css` / `script.js` — sistema visual e navegação móvel.
- `SITE_REVIEW.md` — revisão visual, conteúdo e checks executados.
- `SOURCE_MANIFEST.md` — proveniência dos fatos e assets.

## Execução local

Sirva esta pasta com qualquer servidor estático local, por exemplo `python3 -m http.server 8000`. Não há dependências, fontes remotas, formulários ou chamadas a serviços externos.

## Escopo factual

Tratamentos, endereço, telefone, estacionamento, responsável técnico e linguagem de ciência/ética foram usados apenas conforme os documentos fornecidos e a evidência oficial listada no manifesto. Nenhum depoimento, prêmio, resultado ou promessa de performance foi inventado.
