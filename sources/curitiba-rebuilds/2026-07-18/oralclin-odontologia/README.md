# Oralclin Odontologia Integrada — static concept build

Single, framework-free static website prepared from the supplied evidence boundary.

## Files

- `index.html`: production-realistic homepage; contains no proposal language or proposal link.
- `proposal.html`: separate independent sales document, marked `noindex`.
- `rationale.html`: compatibility redirect to `proposal.html`.
- `styles.css`, `script.js`: shared presentation and accessible mobile navigation.
- `SOURCE_MANIFEST.md`: fact and asset provenance.
- `SITE_REVIEW.md`: responsive, visual, accessibility, and integrity evidence.

## Local review

Serve this directory over HTTP (for example `python3 -m http.server 4173`) and open the three HTML files. There are no forms, analytics, trackers, or runtime data calls. Telephone, email, official-site, and WhatsApp links are ordinary outbound links and are not exercised during automated review.

The deliverable tier supplied for this run is `production_complete`; this means the static build is complete for review, not that it is approved or published.
