# Design System: Evidence-bounded redesign seed

<!-- Seed scaffold: Impeccable craft must replace inferred choices with an implemented, evidence-compatible system. -->

## Overview

Creative North Star: This concept can only belong to Arch Odontologia because it turns the clinic's own verified care model — Acolher, Arquitetar, Realizar, Manter — into the site's structural spine, pairing named specialists with the exact oral and facial tracks the clinic already runs, in a calm, architectural layout that reads as premium without any fabricated proof.

## Colors

No official brand color values are recoverable from the text-only fetch of the official site (image assets carry the real palette but were not pixel-sampled). Generate a restrained, accessible palette appropriate to a premium dental + facial-aesthetics clinic: a deep ink/charcoal-teal for authority, a warm off-white for calm clinical space, and a single muted terracotta/clay accent for warmth and the facial-aesthetics side of the brand. Document this as a generated (not sampled) palette. WCAG AA contrast required for all text.

## Typography

A distinctive serif or high-contrast display face for headlines (evoking "Arch" — architecture, structure, precision) paired with a clean humanist sans for body copy and UI. Strong numerals for treatment lists and steps. Comfortable line length and spacing on mobile; body text minimum ~16px equivalent.

## Elevation

Flat by default. Use a single thin rule or hairline border motif (echoing an architectural arch/keystone idea) instead of drop shadows or glassmorphism. Avoid nested cards.

## Concept rules

1. Recognizable composition: the four-step care model (Acolher → Arquitetar → Realizar → Manter) as a horizontal/vertical process spine repeated site-wide.
2. Brand-connected typographic idea: an "arch" motif expressed through a single subtle geometric arch/rule element in the header and section dividers — no literal logo redraw.
3. Image-treatment rule: no photography is fabricated; visual interest comes from typography, color blocking, and simple CSS-drawn shapes only.
4. Deliberate color evolution: ink/teal for oral/clinical trust sections, shifting to the clay accent for facial-aesthetics sections, unified by shared neutral background.
5. Verified emotional promise: calm, structured, transparent care — sourced directly from official "trabalhamos de forma transparente" language.
6. Conversion path: one phone/WhatsApp number, stated once in the header and once in the footer/contact section — no form, no popup.

## Components

Semantic HTML5 landmarks (header/nav/main/section/footer), visible focus states, touch-sized nav targets (>=44px), an inert mobile nav toggle (no external JS deps), and a fully separate `proposal.html` page never linked from the public homepage. Establish hierarchy (H1 once, logical H2/H3) before any decorative treatment.

## Do's and Don'ts

Do tailor the system to the verified rebuild opportunity (unify contact number, replace broken/blurred imagery with clean CSS composition, remove fragmented CTAs, keep hero free of any overlay). Don't copy proprietary logos/photos/layouts/substantial text, invent claims, fabricate proof, or use a generic AI landing-page template.
