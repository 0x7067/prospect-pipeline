# Prospect Pipeline

Private archive of the prospect-generation pipeline and website clone/build outputs.

## Included

- `sources/prospect-batch/` — prospect batch pipeline outputs and project artifacts
- `sources/curitiba-rebuilds/` — Curitiba rebuilds, briefs, variants, reviews, and evidence
- `sources/curitiba-rebuilds/2026-07-16/penha-moraes-arquitetura/iterations/kimi/` — consolidated Kimi iterations for the Penha Moraes prospect (initial, build staging, and V2)

## Deliberately excluded

Generated browser binaries, virtual environments, `node_modules`, caches, and other machine-local runtime artifacts are excluded to keep the repository usable and safe to share privately.

This repository is private and intended for the owner's archival and continuation workflow.
